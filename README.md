# Cuentaconmigo – Ionic / Semana 5
Avance de aplicación móvil: resumen, registro, edición, eliminación, filtros, reportes y almacenamiento local en `localStorage`.

## Ejecutar
1. Instalar Node.js LTS.
2. `npm install`
3. `ionic serve`

## APK
La compilación Android requiere Android Studio/SDK, Java y Capacitor. No se incluye APK compilado en esta entrega; consulte las instrucciones de `BUILD_ANDROID.md`.
